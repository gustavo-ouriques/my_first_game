Este jogo foi feito por Gustavo dos Passos Ouriques para a atividade "MyFirstGame" proposta pelo professor Alexandre Bellezi Jose do Instituto Federal de Goias - Campus Anápolis.

O jogo consiste em seguir em frente desviando de esqueletos, campos letais e afins durante 3 fases, podendo ser controlado pelas setas de movimentação do teclado ou WASD + space.
